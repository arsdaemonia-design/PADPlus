=== CONTROLADORES PARA PAD+ ===

1. ViGEmBus (REQUERIDO):
   - ViGEmBusSetup_x64.msi: Driver de emulación de mandos Xbox 360 y DualShock 4.
   - Es indispensable para que Windows y tus juegos reconozcan los mandos de Switch.

2. HidHide (OPCIONAL - RECOMENDADO):
   - HidHide_1.5.230_x64.exe: Driver moderno de Nefarius para ocultar el mando DirectInput original de Nintendo Switch.
   - Evita el "doble input" y evita que Windows interprete los sensores de movimiento/giroscopio como palancas moviéndose solas.
   - Una vez instalado, PAD+ lo detectará automáticamente y mostrará "HidHide: Activo" en verde.
